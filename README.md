# Nafis Practice Platform

> Interactive web platform for practicing NAFIS reading assessments with student exercises, instant feedback, and teacher progress tracking.

## 📚 منصة تدريبات نافس التفاعلية

منصة ويب تعليمية تفاعلية تم تطويرها لتدريب طالبات الصف الثالث الابتدائي على اختبارات **نافس الوطنية (مادة لغتي)**.

تم بناء المنصة بناءً على احتياج تعليمي حقيقي لمعلمة، بهدف توفير تجربة تدريبية سهلة للطالبات داخل الفصل، مع نظام متابعة يساعد المعلمة على قياس تقدم الطالبات ونتائجهن.

---

## 🔒 Privacy Notice | ملاحظة الخصوصية

النسخة الأصلية من المنصة تحتوي على بيانات طالبات حقيقية، لذلك لم يتم نشر الرابط أو أي بيانات حساسة.


---

# 💡 Project Overview | فكرة المشروع

تتيح المنصة للطالبة:

1. اختيار اسمها من قائمة بدون الحاجة إلى إنشاء حساب.
2. اختيار أحد التدريبات المتاحة.
3. قراءة نص تدريبي والإجابة على أسئلة اختيار من متعدد.
4. الحصول على تصحيح فوري ومعرفة الإجابات الصحيحة.
5. متابعة تقدمها أثناء التدريب.

كما توفر للمعلمة لوحة متابعة خاصة لمراجعة أداء الطالبات ونتائجهن.

---

# ✨ Features | المميزات

## 👩‍🎓 Student Experience

- اختيار الطالبة لاسمها بسهولة بدون تسجيل.
- 14 تدريبًا تفاعليًا.
- كل تدريب يحتوي على:
  - نص قرائي.
  - 10 أسئلة اختيار من متعدد.
  - تصحيح فوري.
- عرض الإجابة الصحيحة بعد الحل.
- شريط تقدم أثناء التدريب.
- إمكانية مراجعة النص أثناء الإجابة.
- حفظ تقدم الطالبة.

---

## 👩‍🏫 Teacher Dashboard

- نظام تسجيل دخول خاص بالمعلمة.
- متابعة الطالبات اللاتي أكملن التدريبات.
- عرض درجات ونتائج التدريبات.

# 🎯 What I Learned | ما تعلمته

- تحويل احتياج تعليمي حقيقي إلى منتج ويب قابل للاستخدام.
- تصميم تجربة مستخدم مناسبة للأطفال مع واجهة بسيطة وتغذية راجعة واضحة.
- تطبيق فصل الصلاحيات بين الطالبة والمعلمة.
- استخدام Firebase Authentication لإدارة وصول المستخدمين.
- نشر وتحديث التطبيقات باستخدام Netlify.
- التعامل مع خصوصية بيانات الأطفال وعدم نشر المعلومات الحساسة.
